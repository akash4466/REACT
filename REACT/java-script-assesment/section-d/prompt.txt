Write a JavaScript program that fetches a list of food items from https://jsonplaceholder.typicode.com/posts (treat each post title as a dish name) using fetch() and async/await. Render the items in an HTML <ul>, with an 'Add to Favourites' button next to each item. Save the user's favourite items to localStorage and re-load and highlight them correctly when the page is refreshed. Show a loading indicator while the fetch is in progress and display a visible error message in the DOM if the request fails.
